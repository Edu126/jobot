# ADR-075: Coach reactions graded by the answer, capped at moderate

Date: 2026-10-10
Status: Accepted. Supersedes ADR-074's "restate one detail" acknowledgment (the 2.5 s pause stands).
Relates to: REQ-049, REQ-048

## Decision
The coach reacts in a few words matched to the answer's substance: vague →
"Okay." / "Got it."; clear → "Sure, that makes sense."; a real example →
"Good example."; specific with a result → "That's a strong example." Never
stronger (no "wow", "impressive"), never two the same way. Repeat requests
start with "Sure —"; a follow-up names the answer it's about.

## Why
Restating a detail (ADR-074) was accurate but read as a summary, and all five
copied the one example. Eduardo chose graded reactions with a moderate cap
(over full-range praise or neutral-only): human, but a "wow" mid-session would
contradict a "needs work" on Feedback and break trust in both.
