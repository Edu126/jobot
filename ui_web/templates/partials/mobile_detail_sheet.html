{# Mobile bottom sheet for job detail. Fills the gap left by the `hidden lg:block` right-sidebar pattern on jobs_results.html / jobs.html — without this the whole detail-viewing UX vanishes below lg (cards fire HTMX into an invisible target). Opens via Alpine.store('selectedJob').select(id) when the viewport is below lg (see base.html). Dismisses via backdrop tap, close button, or hardware Back on Android. Same HTMX target endpoint as desktop (/jobs/detail/{id}) — server doesn't need to know about viewport. The partials/job_detail.html content stays identical; the sheet just wraps it. NOT rendered on desktop (`lg:hidden`) — the sticky right pane wins. #}
